## 一、为什么这是当前最优工作

在上一轮完成 **RQ3 严格零值滞后消融**后，我们逐项复盘全稿发现：原研究问题 **RQ2**（*how single- and dual-unit capability loss interacts with island balancing, reserve response and branch-removal rules*）在有限储热修正（`v0.7.2`）后仍保留了一处证据缩水——
- 此前 §3.2 与 §4.4 因历史 `code/examples/dc_minimal_validation_v07.csv`（8行）和 `m2_cascade_robustness.csv`（60行）中的部分减出力状态（`S3a_dual_derate`）及非对称双机补水中断中间跳机状态（`M6_detuned_at_first_trip`）源自旧版 `v0.7.0` 热轨迹，将其排除在现行证据之外，仅保留了30行零能力固定上限子集（`G33=0` 与 `G33=G34=0`）。
- 这种缩水使 RQ2 缺少了**“温和双机部分减出力（S3a）能否被备用响应无损吸收”**以及**“非对称双机退化在第一台机跳机、第二台机处于中间减出力时的电网级联后果是否可由单机/双机全停端点线性外推”**这两个最具物理与工程价值的证据。

因此，本轮在不改动任何计算核心、不做AC潮流、不覆盖此前 **255个受保护文件**的前提下，使用 `v0.7.2` 有限储热模型重新推导了 G33（652 MW）与 G34（508 MW）的全部热输入，重耦合了完整的 **8行最小门禁 + 60行规则/评级与同步/非对称矩阵 + 12行非对称首跳评级敏感性（共80次级联求解）**，更新了 **Figure 4**、**Table 4** 与 **Table 5**，实现了 **RQ1、RQ2、RQ3 三个原研究问题的完整证据闭环**。

## 二、RQ2重耦合核心科学发现（已写入摘要、§3.2、§4.4 Table 4/5、Fig. 4、§5.3与§6）

1. **`v0.7.2` 热输入重推导与步长不变性**：
   - **`S3a` 双机 50% 失泵准稳态减出力（8 h）**：`G33 = 615.715 MW`、`G34 = 479.729 MW`，合计较初始无损出力（`632 + 508 = 1140 MW`）减少 `44.556 MW`。
   - **非对称双机补水中断（G34 水池面积乘子 `0.85`）**：G34 在 $t_1 = 4.273889\ \mathrm{h}$（`15386.0 s`）先行低液位跳机为 `0 MW`，此时 G33 处于 SOP 降负荷途中，可用能力上限为 `351.663 MW`（合计出力缺额 `788.337 MW`）；随后 G33 在 $t_2 = 5.047222\ \mathrm{h}$（`18170.0 s`）低液位跳机为 `0 MW`（双机全停，缺额 `1140.0 MW`）。
   - **四倍步长细化检验**：将热步长从 $\Delta t=1.0\ \mathrm{s}$ 细化至 $0.25\ \mathrm{s}$，$t_1$ 与 $t_2$ 完全不变，$t_1$ 时刻 G33 可用能力仅变化 `0.0061 MW`，级联切除支路数、轮数与孤岛数完全不变，终端切负荷变化 `< 0.007 MW`。
2. **温和部分减出力（`S3a`）在 `S` 与 `H` 策略下的定性分岔**：
   - 在全部 6 种支路移除规则与评级乘子（`1.0 / 0.9 / 1.1`）下，`S` 策略（无发电上调）均按比例切负荷 `44.556 MW`（`0` 支路切除），而 `H` 策略（按剩余裕度上调出力）完全吸收该 `44.556 MW` 缺额，实现 **`0.0 MW` 切负荷、`0` 支路切除**。
3. **非对称首跳中间状态（`Detuned 1st trip`）在 `H` 策略下的强非单调放大效应**：
   - 在额定评级（`1.0`）、同步移除（`simultaneous`）下，随着湿冷机组失电规模从 `S3a`（缺额 `44.6 MW`）增至 `G33` 单机跳机（缺额 `632.0 MW`）、非对称首跳（缺额 `788.3 MW`）与双机全停（缺额 `1140.0 MW`）：
     - `S` 策略终端切负荷单调增加：`44.556 → 632.0 → 788.337 → 1140.0 MW`（均 `0` 支路切除）；
     - `H` 策略终端切负荷呈**显著非单调峰值**：`0.0 → 1753.2 → 1909.537 → 1087.230 MW`（切除支路分别为 `0 [0] → 12 [3] → 11 [3] → 3 [1]`，终端孤岛数分别为 `1 → 8 → 8 → 3`）。
   - **物理机制**：在 $t_1=4.274\ \mathrm{h}$（`G34=0`、`G33=351.663 MW`），`H` 策略将 `788.337 MW` 缺额分摊给其余发电机（而 G33 被上限锁死在 `351.663 MW`），触发与 G33 单机全停相同的 3 轮解列模式（8 个孤岛），同时在解列后的孤岛内多出 `156.337 MW` 发电缺额，导致其终端切负荷（`1909.5 MW`；在 `0.9` 评级下更达 `14` 条支路、`5` 轮、`3154.9 MW`）反而显著高于双机全停（`1087.2 MW`）。
   - **方法学边界**：正文与图注均明确声明，这些快照是从完整电网初态独立求解的静态能力上限探针，不宣称是携带 $t_1$ 残余孤岛拓扑进入 $t_2$ 的连续时域级联。
