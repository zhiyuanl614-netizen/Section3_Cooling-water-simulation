# 电网级联模型与母线最终失供判定

## IEEE30 数据与基准状态

项目唯一电网算例为 IEEE30。冻结数据表位于 `data/grid/IEEE30/`：`bus.csv`、`gen.csv`、`branch.csv`、`gencost.csv` 及数据元信息 `metadata.json`。`src/grid/cases.py` 从这些表装配 PYPOWER case，不再隐式依赖 PYPOWER 包内另一个可能不同版本的 case30 数据。潮流求解器仍依赖 PYPOWER。

IEEE30 含 30 母线、6 台机组、41 条支路，`baseMVA=100`；基准负荷为 189.20 MW。无故障初态通过 AC 潮流检验并存于 `results/K0_baseline/`。基准有功平衡由 slack 机组潮流自动修正；K1 六案与未来 K2 所有组合均从同一基态重新建立。

## 级联事件流程

`src/grid/cascade.py` 实现准稳态 AC 级联；`src/grid/vcls.py` 处理初始 AC 潮流失败时的减载可支撑性搜索。每一网侧事件按以下顺序执行：

1. 切除已跳机设备、更新在线支路并拆分电气孤岛；
2. 无在运电源的孤岛标记 F3、去电并从算例移除；
3. 对有源孤岛求 AC 潮流。全负荷潮流不可行时调用 VCLS；若仍无可行解，将该孤岛记为数值失败端点并移出服务（不计入 H）；若有可行解则按比例切负荷并继续状态判定；
4. 对求解成功的母线记录电压越限/严重低压等过程量（F1/F2a），仅作演化过程记录，不构成失效判据；再检查线路过载、机端保护和 UVLS/UFLS 等动作；
5. 新动作发生时进入下一准稳态阶段，无新动作时结束该事件级联。

此处是准稳态断面级联，不是电磁暂态仿真；中间时域爬坡的每秒电压不会被连续计算。保护门槛是本模型的研究设置，不应直接解释为现场继电器整定或设备损坏。

## 必须区分的母线状态

| 状态 | 操作含义 | 是否计入最终硬失供 H |
|---|---|---:|
| F1 | 电压低于该母线 VMIN 或高于 VMAX（过程量） | 否 |
| F2a | 电压低于 0.80 pu 的严重低压过程标记 | 否 |
| F2b | VCLS 后仍无可行 AC 潮流，模型将孤岛移出服务（数值失败端点，仅披露） | 否 |
| F3 | 母线所在孤岛无在运电源，模型将其去电 | 是 |
| F4/切负荷 | UVLS、UFLS、VCLS 等负荷削减后果 | 否，MW 单列 |
| F2c | 发电机母线电压保护所致的机组退出动作标签 | 否，不是母线端点 |

当前主判据为

$$H_b=\mathbf{1}[F3_b]$$

即**仅无源失电**（级联演化后的拓扑中母线所在孤岛无在运电源）计入硬失供。F2b 是求解器数值失败端点，仅作为披露项与切负荷/频率次级量的可信度约束，并不声称实物母线损坏，也不计入 H。F1/F2a 电压状态仅为演化过程量。VCLS 若找到任一可行减载潮流（甚至全负荷无法供电但某个负荷比例可行），当前代码记为切负荷后果而非任何失效判据。

## 指标口径（2026-10 修订）

指标定义集中在 `src/coupling/metrics.py`，所有汇总字段由该模块单点构造，避免多处实现产生口径分歧。本次修订把判据定为 **$H=1[F3]$**（仅无源失电），F2b 不再计入硬失供，F1/F2a 彻底移除失效语义（仅保留为演化过程量）。

### 1. 严重度：`bfi` 基于 H，并增加负荷加权口径

旧 `bfi` 使用含 F1 的旧复合字段 `n_bus_failed`，实测导致两案 `bfi` 完全相同却后果相反（一案 H=28 近全网崩溃、一案 H=0 正常供电）。现字段（旧失效列 `bfi_legacy_composite`、`n_bus_failed`、F2a/F2b 母线列均已删除）：

| 字段 | 含义 |
|---|---|
| `n_bus_hard_failure` / `hard_failure_buses` | H 母线条数与集合（**主端点**，等于 `n_f3_deenergized`） |
| `h_load_ratio` / `h_load_mw` | 负荷加权硬失供比例 $\sum_{b\in H}P_b/\sum P$ |
| `bfi_hard` | $n_{H}/30$，与 H 一致 |
| `bfi_load` | 等于 `h_load_ratio` |

母线负荷不等，故计数法与负荷加权法并列报告；本算例两者单调同向（差 5–8 个百分点），但跨系统未必成立。

### 2. 影响类别：N3 与 H 严格一一对应

旧实现中 F2a 单独即可触发 N3，使 H=0 的案例被标为 N3。现类别简化为两档，与 H 严格对齐：

$$N3 \iff H>0;\qquad N0 \iff H=0$$

H=0 案不再有 F2a 触发的 N2/N1；类别仅是运行标签，不承载严重度排序。

### 3. 切负荷：三量分列

`total_shed_mw` 为各阶段切负荷动作量累计，可能超过全网负荷（K4-G1-G2-G13-G22 达 160.6MW／189.2MW），**不是未供电量**。新增 `shed_peak_mw`（任一阶段最大累计切负荷）。三者均不等于 EENS/MWh。

### 4. 时间维度与删失披露

新增 `t_first_hard_s`/`t_first_hard_h`（首次硬失供时刻，H=0 时留空）、`observation_window_h`（实际观察时长，使删失效应可见）。

### 5. 收敛性审计

`solver_converged`、`n_singular_warnings`、`n_divergence_warnings` 由 `metrics.ConvergenceAudit` 在**整个仿真范围**内采集（基准潮流、时域频率推进、各级联断面），作为切负荷/频率等次级量的可信度约束——H=F3 是拓扑判定，不依赖求解器收敛性。

实测：K4-G1-G2-G13-G22 与 K5-G1-G2-G13-G22-G27 各捕获 60 条 `MatrixRankWarning` + 54 条 `RuntimeWarning`（源自 `newtonpf` 的雅可比奇异），标记 `solver_converged=False`。这两案的 H 值（25/29）为拓扑判定不受影响，但其切负荷/频率等次级量应作为**条件性结果**引用。文件级 NaN/Inf 审计不能替代此项。

### 6. 指标退化披露

K4-G1-G13-G22-G23 与 K4-G13-G22-G23-G27 等多组案例在 (H, F3, 切负荷, 最低频率) 上完全一致，网格后果不可区分。`src/analysis/metric_audit.py` 会列出退化组，提示这些案例**不是相互独立的验证**。

### 审计工具

```bash
python3 src/analysis/metric_audit.py --csv results/analysis/metric_audit.csv
```

校验 H 与 F3 的一致性（$H=1[F3]$）、N3⟺H>0、`bfi_hard` 与 H 的关系、切负荷三量语义、$t_{first\_H}$ 是否落在观察窗口内、案数完整性（63 案）与收敛性披露，并输出退化组。存在不自洽项时退出码为 2。

输出中已移除全部旧失效语义列（`n_bus_failed`、`bus_failure_definition`、`bfi_legacy_composite`、F2a/F2b 母线列等）。`n_bus_hard_failure` / `hard_failure_buses` 与 `n_f3_deenergized` 严格相等，是唯一硬失供口径；F1/F2a 过程量、切负荷与 H 各列分别报告。N0/N3 是运行影响类别，并非 H 的替代定义。

## 实现注意事项

1. 电压限值采用 IEEE30 数据中的逐母线 VMIN/VMAX。下限为 0.95 pu；上限并非全网统一 1.05 pu，部分母线为 1.10 pu。
2. 旧版曾把静态级联用的 `f_uf=[0,0,0]` 共用给 SFR，导致时域 UFLS 不可触发。现已拆分 `cfg_grid` 与 `cfg_freq`：静态 CascadeSim 可关闭其内置频率保护，时域 SFR 保留 59.30/58.90/58.50 Hz 定值。合成大缺额探针验证时域 UFLS 可触发；K1/K2 实际最低频率均未低于首档，所以实际算例 UFLS 为 0。
3. K1 未触发 F3；K2 新增了 F3 动态正例：G1+G2 两机依次跳闸后，23 条母线进入无源孤岛 F3（H=23/30）。K2 其余案及 K3–K6 中的 H=0 案均未触发 F3。

代码：`src/grid/cases.py`、`src/grid/cascade.py`、`src/grid/vcls.py`。
