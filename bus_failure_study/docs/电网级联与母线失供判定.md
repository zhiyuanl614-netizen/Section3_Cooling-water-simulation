# 电网级联模型与母线最终失供判定

## IEEE30 数据与基准状态

项目唯一电网算例为 IEEE30。冻结数据表位于 `data/grid/IEEE30/`：`bus.csv`、`gen.csv`、`branch.csv`、`gencost.csv` 及数据元信息 `metadata.json`。`src/grid/cases.py` 从这些表装配 PYPOWER case，不再隐式依赖 PYPOWER 包内另一个可能不同版本的 case30 数据。潮流求解器仍依赖 PYPOWER。

IEEE30 含 30 母线、6 台机组、41 条支路，`baseMVA=100`；基准负荷为 189.20 MW。无故障初态通过 AC 潮流检验并存于 `results/K0_baseline/`。基准有功平衡由 slack 机组潮流自动修正；K1 六案与未来 K2 所有组合均从同一基态重新建立。

## 级联事件流程

`src/grid/cascade.py` 实现准稳态 AC 级联；`src/grid/vcls.py` 处理初始 AC 潮流失败时的电压崩溃负荷可支撑性搜索。每一网侧事件按以下顺序执行：

1. 切除已跳机设备、更新在线支路并拆分电气孤岛；
2. 无在运电源的孤岛标记 F3、去电并从算例移除；
3. 对有源孤岛求 AC 潮流。全负荷潮流不可行时调用 VCLS；如果任何允许负荷比例下仍无潮流解，标记 F2b、移出服务；若有可行解则按比例切负荷并继续状态判定；
4. 对求解成功的母线记录电压限值越限 F1 与严重低压 F2a；再检查线路过载、机端保护和 UVLS/UFLS 等动作；
5. 新动作发生时进入下一准稳态阶段，无新动作时结束该事件级联。

此处是准稳态断面级联，不是电磁暂态仿真；中间时域爬坡的每秒电压不会被连续计算。保护门槛是本模型的研究设置，不应直接解释为现场继电器整定或设备损坏。

## 必须区分的母线状态

| 状态 | 操作含义 | 是否计入最终硬失供 H |
|---|---|---:|
| F1 | 电压低于该母线 VMIN 或高于 VMAX | 否 |
| F2a | 电压低于 0.80 pu 的严重低压标记 | 否（单独出现时） |
| F2b | VCLS 后仍无可行 AC 潮流，模型将孤岛移出服务 | 是 |
| F3 | 母线所在孤岛无在运电源，模型将其去电 | 是 |
| F4/切负荷 | UVLS、UFLS、VCLS 等负荷削减后果 | 否，MW 单列 |
| F2c | 发电机母线电压保护所致的机组退出动作标签 | 否，不是母线端点 |

当前主判据为

$$H_b=\mathbf{1}[F3_b\lor F2b_b]$$

若以后显式建模母线断路器动作 $T_b$，应扩展为 $H_b=\mathbf{1}[F3_b\lor F2b_b\lor T_b]$。F2b 是当前计算模型中的“不可服务”代理，并不声称实物母线损坏。VCLS 若找到任一可行减载潮流（甚至全负荷无法供电但某个负荷比例可行），当前代码记为切负荷后果而非 F2b；只有无可行解才移出服务。

旧兼容字段 `n_bus_failed` 是过程内旧复合指标 $F1_{new}\lor F2a\lor F2b\lor F3$，不代表最终硬失供。`n_bus_hard_failure` / `hard_failure_buses` 才对应 H。F1 过程并集与终态 F1 还分别统计，切负荷与硬失供不可混为一谈。N0–N3 是运行影响类别，并非 H 的替代定义；当前实现中 F2a 也可能使情景进入 N3，但单独 F2a 不构成 H。

## 实现注意事项

1. 电压限值采用 IEEE30 数据中的逐母线 VMIN/VMAX。下限为 0.95 pu；上限并非全网统一 1.05 pu，部分母线为 1.10 pu。
2. 旧版曾把静态级联用的 `f_uf=[0,0,0]` 共用给 SFR，导致时域 UFLS 不可触发。现已拆分 `cfg_grid` 与 `cfg_freq`：静态 CascadeSim 可关闭其内置频率保护，时域 SFR 保留 59.30/58.90/58.50 Hz 定值。合成大缺额探针验证时域 UFLS 可触发；K1/K2 实际最低频率均未低于首档，所以实际算例 UFLS 为 0。
3. K1 未触发 F2b/F3；K2 新增了 F3 动态正例：G1+G2 两机依次跳闸后，23 条母线进入无源孤岛 F3。K2 本批未触发 F2b。
