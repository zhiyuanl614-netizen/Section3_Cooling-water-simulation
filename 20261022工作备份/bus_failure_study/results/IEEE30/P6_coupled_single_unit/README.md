# IEEE30 单台机组补水中断：G1 / G2 / G22 / G23 / G27

## 场景边界

本目录新增五个**互相独立**的单机补水中断情景；每次只中断所列一台机组，其余机组保留独立冷却水系统、正常补水并按动态出力响应。沿用 G13 主线的时序流程：冷端低水位保护触发初始跳机 → 频率/一次调频与限速再调度 → 按实际 Pg(t) 推进冷端热负荷、补水需求和池位 → 冷端保护退出反馈电网 → 准稳态网侧级联。只有达到 F3/F2b 硬失供才提前停止；F1/F2a 单独不截断反馈，无硬失供时跟踪至 24 h。

- **统一运行点**：IEEE30 原始基准负荷，Pd=189.200 MW；基态 AC 潮流后总 Pg=191.6438 MW。未做 λ 扫描。
- **初始事件**：每个场景单独触发 G1、G2、G22、G23 或 G27 的补水中断，不是多机同时断水，也不是在 G13 已退出后再触发。
- **显式参考假设**：5% Pmax/min 上调速率、10 s 再调度命令延时、补水能力=满负荷设计需求、补水响应时间常数 60 s、UFLS 延时 0.2 s、初次退出后最长跟踪 24 h。具体值与依据列在本目录 `assumptions_used.csv`，每个场景子目录也留有副本。
- 现场数据缺失；以上假设**不是现场数据、不是现场整定值，也未标定**。冷端物理内核 `src/coldend/model.py` 未改动。
- 出力爬坡、SFR 和冷端状态逐秒/逐步推进；线路、电压与母线级联仍在网侧准稳态事件点求解，并非完整电磁暂态联合仿真。

## 多指标综合判定

为避免把电压越限直接等同于黑停，本批采用**分层判据 + 指标向量**，不把未经标定的权重硬凑成单一总分：

| 等级 | 判定 | 含义 |
|---|---|---|
| **N0** | 无新增电压限值越限，无保护/安控动作，无切负荷或失电 | 本模型下未记录异常 |
| **N1** | 有 F1 电压限值越限，但没有电压崩溃、失电、保护切除或切负荷 | 电压安全约束不满足，**不称黑停** |
| **N2** | 发生 UVLS/UFLS、线路/发电机保护等应急动作或受控切负荷，但未达到 N3 | 应急控制影响，需同时报告动作和 MW |
| **N3** | F2 电压崩溃/潮流不可解或 F3 无源岛失电 | 严重电压/拓扑失效；仍需报告实际失电范围，不能默认等于全网黑停 |

本研究的“硬失供”出口定义为 `F3 ∨ F2b`：无源岛失电，或规定处置后 AC 孤岛仍不可解、模型必须将其移出服务；若模型显式加入母线断路器跳闸，也应计入。F1 与 F2a 单独列为限值越限/严重低压，不直接计作硬失供；部分 UVLS 属应急影响，另报切负荷 MW。`n_bus_hard_failure` 是按上述规则得到的计数，`hard_failure_buses` 给出母线清单，`hard_failure_definition` 随每案写入 CSV。另行报告 `n_f1_new`（过程内越限）、`n_f1_terminal`（末级仍越限）、F2a/F2b/F3、`n_bus_dead`、应急动作、切负荷、频率最低点和 RoCoF。N0–N3 是运行状态类别，**不是单一严重度排序**：例如 G22 的持续 F1 母线更多，G27 则多了 UVLS/切负荷，应结合越限范围、末级状态和失负荷量逐项比较。当前电网层是爬坡终点的准稳态级联，不具备连续电压暂态与继电器计时模型，因此这些类别是当前模型范围内的结果分类，不是现场保护定值或行业标准判级。

按此口径，G13/G1/G2/G23 为 **N0**；G22 为 **N1**（10 个 F1、无应急动作和失电）；G27 为 **N2**（B30 两轮 UVLS、切负荷 2.014 MW；4 个过程 F1，其中末级仍越限 3 个）。两案均为 **硬失供=0、F2=0、F3=0、实际失电母线=0**，所以都不应称为黑停。

## 能量指标口径

`爬坡缺额面积至收敛` 定义为相对级联终态总 Pg 的正向发电补发滞后面积：

\[
E_{gap}[\mathrm{MWh}]=\frac{1}{3600}\int_0^{t_s}\max\left(P_{target}-\sum_iP_i(t),0\right)dt_s.
\]

它由 `dispatch_trajectory.csv` 的动态出力轨迹积分得到，**不是 EENS/用户未供电量**。EENS 需由切负荷随时间的积分另行计算；本次 G27 的 2.014 MW 是准稳态切负荷量，不能与爬坡缺额面积混为一谈。
