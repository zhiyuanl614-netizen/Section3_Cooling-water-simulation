# G13 补水中断—爬坡再调度—冷端需水动态耦合

## 场景与参考假设

- 固定 IEEE30 原始基准负荷：总有功负荷 **189.20 MW**；本主线不扫描负荷倍率。
- 仅 G13 补水中断；关闭排污隔离，不执行 SOP。基态 AC 潮流先求 slack 修正，并将求得的 Pg/Qg 写回网侧与冷端初始状态；因此 G1 冷端初始 Pg 使用 **25.974 MW**，而非原始数据中的 23.540 MW。
- G13 保持 37.00 MW 至低水位保护，在 **2.3003 h** 跳机；此后其他机组按参考爬坡率增发。每个秒步更新机组 Pg、频率、冷端热负荷、补水需求和池水库存。
- 现场无爬坡与补水数据，暂用 `assumptions_used.csv` 中的显式参考假设：各机组上调速率 **5% Pmax/min**、再调度命令延时 **10 s**；正常补水能力取满负荷设计补水量，补水流量响应时间常数 **60 s**；UFLS 继电器延时 **0.2 s**；初次跳机后冷端跟踪 **24 h**，以捕捉可能的后续低水位保护。以上均非现场整定值或现场数据。
- 冷端物理内核 `src/coldend/model.py` 未修改。网侧频率使用降阶 SFR；线路/电压级联在爬坡结束后的终态 Pg 下准稳态求解，不是电磁暂态联合仿真。

## 本次动态结果

- G13 跳机损失 **37 MW**；按参考爬坡率和静态再调度增量计算的命令爬坡窗口为 **237.012 s**。在 SFR/一次调频同时作用下，实际总机组 Pg 到 **242 s** 才首次进入并保持在终态值 ±0.01 MW 内。
- 频率最低点 **59.609 Hz**，高于本模型 UFLS 第一轮定值 59.30 Hz；本次动态 SFR 未触发 UFLS。
- 用逐秒 `dispatch_trajectory.csv` 计算爬坡期间的等效出力缺额面积：
  `E_gap[MWh] = (1/3600) ∫₀ᵗˢ max(P_target − ΣᵢPᵢ(t), 0) dt_s`。终态目标总 Pg 为 **192.5358 MW**；从跳机后 **154.6438 MW** 开始，积分至 Pg 收敛时刻得到 **0.578140 MWh**。仅积分至 237.012 s 命令爬坡终点为 **0.577974 MWh**。这里的 0.578 MWh 是相对于终态出力的“补发滞后面积”，**不是用户未供电量/EENS**。本情景 UFLS 和静态切负荷均为 0，因此模型内切负荷造成的未供电电量为 0。
- 爬坡结束后的准稳态网侧计算：母线失效 **0/30**，无额外发电机跳闸、无额外静态切负荷；24 h 冷端跟踪期内也没有二次保护退出。
- 幸存机组补水需求由 **402.728 增至 484.391 m³/h（+81.663 m³/h，约 +20.3%）**；G13 停机后自身需求归零，所以六台合计需水从 497.389 降至 484.391 m³/h。

在当前假设的满负荷设计补水能力下，24 h 跟踪期内幸存机组补水均未达上限，池位仅有小幅动态下降，没有后续冷端跳机。若某机组确实触发低水位保护，事件循环会保留其他机组当时的冷端状态与 Pg，令其从当前网侧状态退出，重新求解再调度/爬坡和终态母线级联，再继续跟踪其他在线机组。当前参考结果没有触发这条二次事件分支；较低供水能力下的轨迹不能冒充本次参考结果。

## 输出与复现

- `dispatch_trajectory.csv`：逐秒 Pg、频率、一次调频/再调度增量与 UFLS 状态。
- `cooling_demand_response.csv`：每台机组最长 24 h 冷端需求与池位轨迹，1 min 采样；若有二次跳机则延续到网侧事件/时域终点，Pg 在每段再调度爬坡期间按秒驱动。
- `redispatch_cooling_demand.csv`：基态与动态终值的逐机组 Pg、补水、热负荷和池位统计。
- `cascade_summary.csv`：事件时间、频率、命令爬坡/出力收敛时间、补发滞后能量面积、终态母线级联与补水总量。
- `assumptions_used.csv`：所用参考假设及其来源说明。
- 复现：`cd /home/user/bus_failure_study && ./run.sh coupled`。

## 适用边界

这版比前一轮“Pg 瞬时阶跃”推进了一步：机组增发按时间爬坡，冷端需水与水池状态同步更新；若其他机组保护跳闸，代码会继续反馈到网侧再调度/级联并携带剩余冷端状态。当前补水能力设为满负荷设计值，因此 24 h 参考运行没有触发这条二次事件分支。爬坡率、AGC/调速参数和补水能力均为参考假设，得到的是暂定情景结果，应在取得现场数据后替换并重跑。
