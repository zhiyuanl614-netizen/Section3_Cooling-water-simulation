# 无历史数据条件下的通用机理模型参数化方法

> 当前论文路线：**文献与标准锚定的通用参数标定 + 机理守恒闭合 + 不确定参数敏感性分析**  
> 不是：某电厂历史数据拟合  
> 研究目的：解释冷却水故障如何经冷端运行机理传播为机组降额/跳机，并在电网裕度不足时进一步转化为失供影响。

---

## 1. 为什么当前研究不需要先获得历史数据

本研究的主问题不是“预测某一台已命名机组在某一天几点停机”，而是：

1. 补水中断后，水量、池水位、循环泵、冷却塔、凝汽器、背压、汽轮机能力和保护逻辑如何依次变化；
2. 为什么把冷却水故障简化为瞬时跳机、固定库存时间跳机或预设线性降额，会改变机组交付电量和电网失供结论；
3. 冷却水系统故障在什么条件下只是机组内部事件，什么条件下会经出力轨迹传播成电网充裕性问题。

因此，当前阶段可以采用一台**通用湿冷燃煤机组原型**：参数不由某厂历史数据拟合，而由标准规范、公开文献、厂家典型曲线、热力学/水量守恒关系和透明的场景范围共同锚定。对不能由文献唯一确定的参数，不把单点值写成确定事实，而是进行单因素、Morris、Sobol 和 Monte Carlo 场景分析。

这条路线在论文中应称为：

> **文献与标准锚定的通用参数标定（literature- and standard-anchored generic parameterization）**

它与“厂级历史数据标定”不同：前者建立可迁移的机理模型和参数范围，后者面向某一台机组的本地化预测。历史数据工具仍保留为未来可选的本地化接口，但**不是当前研究成立的前提**。

## 2. 参数证据分层

| 层级 | 证据类型 | 用途 | 示例 |
|---|---|---|---|
| G1 | 热力学与水量守恒、设计点闭合 | 不允许参数任意取值的硬约束 | 蒸发热平衡、盐平衡、NTU/UA 设计点反算、池体容积关系 |
| G2 | 标准/规范与行业设计范围 | 锚定设计湿球、approach、range、TTD、水质与机组运行范围 | 冷却塔设计参数、浓缩倍率、技术最小负荷范围 |
| G3 | 公开文献与厂家典型曲线 | 锚定变工况关系和设备状态范围 | 背压修正 0.5%–1.5%/kPa 量级、泵扬程/NPSHr 曲线形态、塔/凝汽器变流量指数 |
| G4 | 通用机组原型与透明场景假设 | 文献不能唯一确定的几何、SOP 与保护组合 | 池面积、SOP 起始水位、低水位定值、低真空定值 |
| G5 | 敏感性与概率场景传播 | 判断结论是否依赖某个单点假设 | OAT、Morris、Sobol、Latin-hypercube Monte Carlo |

`data/parameter_registry.csv` 中新增了三列：

- `generic_anchor_type`：该参数在通用版本中的锚定类型；
- `generic_anchor_note`：取值依据与不可过度解释的边界；
- `sensitivity_treatment`：采用固定闭合、单因素、全局敏感性还是场景传播处理。

原有 `calibration_status=reference_template_not_site_measured` 保留为机器可读的防误称标记，含义是“尚未用某电厂实测数据本地化”，**不表示模型只能等待历史数据才可使用**。

## 3. 通用 500 MW 原型的参数标定顺序

### 3.1 先用守恒关系固定设计点

以 500 MW 通用原型为母型，先给定净效率、凝汽器废热分额和设计冷却范围，再由：

\[
Q_c=P\left(\frac{1}{\eta_{net}}-1\right)f_{cond}
\]

和

\[
Q_{cw}=\frac{Q_c}{\rho c_p \Delta T}
\]

闭合凝汽器排热与循环水量。当前设计点为 \(Q_c=750.5\) MWth、\(Q_{cw}=15.77\) m³/s、\(\Delta T=11.42\) K。

### 3.2 由设计 approach/TTD 反算设备能力

冷却塔不直接输入一个脱离工况的冷水温度，而是由设计 range 与 approach 反算效能和 NTU；凝汽器不固定 TTD，而是由设计热负荷、range 与 TTD 反算 UA，运行中再由实际流量和清洁度修正。

这样，塔特性倍率、风量、水量、凝汽器清洁度和湿球温度变化都可以沿物理链条改变 Tin、Tout、Tsat 和背压。

### 3.3 用热平衡和盐平衡标定水量

蒸发量由

\[
E=\frac{f_{evap}Q_c}{\rho h_{fg}}
\]

计算，参考 \(f_{evap}=0.82\)，并以文献常见的蒸发潜热承担大部分塔排热为范围依据；排污由浓缩倍率盐平衡决定，飘滴采用厂家除水器典型小量级。补水量是三者之和，而不是预先指定的常数比例。

### 3.4 用厂家原型曲线标定泵与水位

通用泵模型使用流量—扬程和流量—NPSHr 的原型曲线形态，并随池水位改变静扬程和汽蚀裕量。池体不使用抽象的“可撑小时数”制造容积，而显式给定面积、正常水位和跳泵水位；`holdup` 只作为结果诊断量导出。

### 3.5 用规程型规则标定运行与保护

默认 `ride_down` 表示按低水位 SOP、背压能力和负荷爬坡逐步降额；`hold_load` 是冻结热负荷的保守反事实。技术最小、爬坡、低真空定值和泵低水位以文献/规程范围内的代表值进入模型，并通过场景参数改变。因为这些量并非某厂定值单，论文中只能称规程型通用规则，不能称某机组保护整定复现。

### 3.6 容量缩放只生成 IEEE 39 等效算例

500 MW 原型按容量比例缩放循环水量与池面积，生成 G33（Bus 33，652 MW）与 G34（Bus 34，508 MW）两个等效机组；容量取 MATPOWER case39 的 Pmax，与手稿 Table 3 一致。缩放的目的在于把同一种冷端故障机理嵌入标准电网算例，而不是声称这两台 IEEE 39 发电机对应两台真实电厂机组（case39 中 Bus 33/34 的机组标签为 fossil02/fossil01，仅为算例自带分类）。

## 4. 参数处理方式

| 参数组 | 通用锚定方式 | 不确定性处理 | 主要影响输出 |
|---|---|---|---|
| 净效率、废热分额、设计水量 | 文献典型值 + 热平衡闭合 | 设计点包络 | Qc、Qcw、补水需求 |
| approach、TTD、设计背压 | 标准/厂家设计范围 + NTU/UA 反算 | 设计闭合检查 | Tin、Tout、Tsat、pb |
| 塔特性、NTU 指数、风量比 | 厂家/文献变工况关系 + 状态倍率 | OAT + Morris + Sobol + Monte Carlo | Tin、背压、初期能力、降额起点 |
| 凝汽器清洁度、UA 流量指数 | 文献换热关系 + 结垢状态范围 | OAT + Morris + Sobol + Monte Carlo | TTD、背压、能力 |
| 蒸发热份额、CoC、飘滴 | 热/盐平衡 + 文献与水质范围 | OAT + Morris + Sobol + Monte Carlo | E、B、M、水位下降、停机时间 |
| 背压灵敏度 | 文献/厂家修正曲线量级 | 场景与机制检查 | Pavail、背压保护、降额 |
| 池面积、正常/跳泵水位 | 通用几何场景 + 显式水位状态 | OAT + Morris + Sobol + Monte Carlo | 库存、停机时间、机制 |
| 泵扬程、NPSHr、静扬程 | 厂家原型曲线 | OAT + Morris；参考点机制检查 | Qcw、汽蚀、低水位跳泵 |
| SOP 水位、技术最小、爬坡 | 规程型运行规则范围 | OAT + Morris + 场景传播 | 降额轨迹、交付电量 |
| 低真空定值与延时 | 文献/规程代表范围 | 场景传播；不可由单次事件反辨识 | 背压保护概率 |

敏感性分析的作用不是“证明参数真实”，而是回答：

- 哪些通用参数会改变停机时刻和机制；
- 哪些参数只改变初期背压，不改变低水位主导的停机；
- 哪些结论在文献允许范围内仍然稳健；
- 哪些结果只能报告范围，不能报告单点。

## 5. 本研究要弥补的黑箱问题

以往电力系统研究常把冷却水故障写成下列形式之一：

| 黑箱/半黑箱表达 | 缺失的物理过程 | 可能造成的偏差 |
|---|---|---|
| 故障发生即机组瞬时跳机 | 水库存、泵、背压和 SOP 渐进过程 | 高估故障早期容量损失和失供电量 |
| 满出力持续固定小时后跳机 | 负荷、水温和水损失随时间变化 | 降额起点与停机机制不可解释 |
| 预设线性降额曲线 | 降额斜率与设备状态脱钩 | 交付电量和保护动作由人为曲线决定 |
| 用单一经验系数把水量映射为出力 | 塔—凝汽器—背压因果链缺失 | 高温、结垢、泵退化等状态无法区分 |
| 只给最终停机时间 | 中间状态不可审计 | 无法判断是水位、汽蚀、真空还是技术最小触发 |

本模型把故障传播写成显式状态链：

\[
M_{ext}=0
\rightarrow E+B+D
\rightarrow H(t),V(t)
\rightarrow Q_{cw}(t),\mathrm{NPSH}(t)
\rightarrow T_{in},T_{out},T_{sat},p_b
\rightarrow P_{capability},P_{avail}
\rightarrow \text{trip mechanism}
\rightarrow \text{DC-OPF load shedding}
\]

并保留一条反馈：`ride_down` 降负荷后，凝汽器排热和蒸发损失下降，水位下降速度随之减缓。正是这条反馈使降额策略、低水位跳泵和停机时刻不能被一个固定小时数替代。

机理图见 `docs/figures/cooling_grid_causal_chain.svg`。

## 6. 从冷却故障到电网故障的正确表述

冷却水故障不会在任何电网条件下都必然造成系统故障。它先造成单机冷端能力下降、降额或跳机；只有当电网负荷水平、备用和网络约束不足以吸收这条出力轨迹时，才进一步表现为失供。

因此论文中应使用以下表述：

> 冷却水故障是源头事件；机组降额/跳机是设备层响应；失供是电网在特定负荷和裕度条件下的系统层后果。

当前 B 档结果显示：在 IEEE 39 负荷 ×1.00 时，Bus 34（508 MW）全额失能力的增量失供很小，而 Bus 33（652 MW）因 2–3 走廊（rateA 500 MVA）成为约束而产生约 122 MW 增量失供；在 ×1.15 和 ×1.20 时，出力轨迹会被放大为数百 MW 的增量失供。这一对比本身就是冷却—电网耦合研究的重要结论：同一冷端故障的系统后果由电网裕度和映射机组所在位置共同调制。

## 7. 当前可以与不可以主张的结论

### 可以主张

- 建立了一个非黑箱的湿冷机组冷端运行机理模型；
- 参数由文献、标准、守恒关系和透明场景范围锚定；
- 能解释降额起点、停机时刻、停机机制和策略差异；
- 能量化简化停机假设对交付电量和电网失供的偏差；
- 能识别控制结果的通用参数及结论稳健范围；
- 能把单机冷端故障耦合到 IEEE 39 的容量充裕性/DC-OPF 分析。

### 不可以主张

- 已完成某电厂机组的实测标定；
- G33/G34 是两台已辨识的实体机组（它们只是把通用原型嵌入标准算例的等效机组）；
- 5.07 h 是某电厂实际停机预测；
- 合成 Monte Carlo 的 P05–P95 是某台真实机组的统计预测区间；
- 冷却水故障必然导致实际电网故障或级联停电。

## 8. 推荐论文表述

推荐题目：

> **补水中断下燃煤机组冷端渐进失效机理及电网充裕度影响：文献与标准锚定的通用模型与 IEEE 39 算例**

核心贡献可写为：

1. 提出由水量平衡、池水位、泵水力、冷却塔 NTU、凝汽器 UA-LMTD、背压修正、SOP 与保护逻辑构成的显式冷端故障传播模型；
2. 在无厂级历史数据条件下，建立文献与标准锚定的通用参数标定和敏感性分析方法；
3. 通过与瞬时跳机、固定库存时间和预设降额等黑箱/半黑箱表达对照，量化其对机组交付电量和电网失供的系统偏差；
4. 揭示冷端故障向电网失供转化的条件性：结果同时受冷端参数和电网负荷裕度控制。

未来如取得厂级历史数据，可在不改变模型结构的情况下进行本地化标定和独立验证；这属于后续扩展，不是当前通用机理研究的必要前提。

## 9. 主要依据类型

- GB/T 50102《工业循环水冷却设计规范》及冷却塔/循环水处理相关标准：设计环境、塔型与水系统设计范围；
- GB/T 7190 系列机械通风冷却塔标准：塔性能与试验口径；
- DL/T 5339 等火力发电厂水工设计规范：水工系统设计边界；
- 汽轮机背压修正、冷却塔变工况、凝汽器 UA 变流量和循环泵曲线的公开文献/厂家资料：变工况关系与参数范围；
- IEEE 39 标准算例：仅作为合成电网拓扑与发电机容量框架。
